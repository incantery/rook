# Answer the terminal's questions: OSC 10/11 and friends

From Vera, 2026-08-25.

## The ask

The engine answers DSR 6 (cursor position) but not OSC 10 / OSC 11
(foreground / background colour queries). Every real terminal answers
them; libraries assume one will. Bubble Tea v1 asks in a package
`init()` via lipgloss/termenv, so any Bubble Tea program spawned into a
pane — `mote demo`, `vera chat`, whatever a fleet agent runs — stalls
for termenv's five-second timeout before its first frame. With an
answer it is microseconds.

Please have the engine reply to:

- `ESC ] 11 ; ? BEL` (or ST) with `ESC ] 11 ; rgb:RRRR/GGGG/BBBB ST`
  for the pane's background colour, and OSC 10 likewise for foreground
  — the configured theme colours, or a sensible default if there is no
  theme.
- while you are there: OSC 12 (cursor colour) if cheap, and make sure
  `CSI 6 n` keeps answering (it does today).

The reply must go to the program's stdin like keyboard input, which is
what a terminal does; it must not be echoed onto the screen.

## How to check

    python3 - <<'PY'
    import os, pty, select, time
    pid, fd = pty.fork()
    if pid == 0: os.execv("/usr/bin/true", ["true"])
    PY

is not enough — run `mote demo` (github.com/incantery/mote, `go run
./cmd/mote demo`) in a fresh pane: with the answer, the greeting appears
at once; without it, the pane is blank for five seconds.
